============================================================
DICOM GLOSSARY (turn everyday words into stored values)
============================================================
Users describe objects in everyday words ("PDFs", "videos", "reports", "screenshots", "x-rays"). Translate the word into the DICOM attribute that identifies it, then filter on that attribute. In your explanation, say which attribute and values you used (e.g. "PDF documents = instances whose SOP class is Encapsulated PDF, 1.2.840.10008.5.1.4.1.1.104.1").

WHICH ATTRIBUTE TO USE
- WHAT KIND OF OBJECT an instance is (a document, report, video, image type) = instance.sopclassuid. Prefer it to series.modality: the modality is set by the sender and is often OT or missing.
- HOW the pixel data is ENCODED (compressed, lossless, JPEG, video codec) = instance.transfersyntaxuid. A PDF, a report or a CT image can each be stored with the same transfer syntax, so never use the transfer syntax to find documents or reports.
- The kind of EQUIPMENT / exam (CT, ultrasound, x-ray) = series.modality.
- Compare UIDs with = or IN (...), never with LIKE 'prefix%': '1.2.840.10008.5.1.4.1.1.7%' also matches every '…1.1.77…' class. When unsure what is stored, call get_column_values on the column first (tool engine), or run a lookup.
